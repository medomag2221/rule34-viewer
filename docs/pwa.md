# Запуск как приложение

Подготовлен режим PWA: manifest.webmanifest, SVG-иконка, standalone-режим,
service worker для оболочки и кнопка установки в настройках (если браузер предлагает установку).
Для установки с телефона разместите приложение на HTTPS; localhost подходит для разработки.
В Safari используйте «Поделиться → На экран Домой». Поддержка SVG-иконок зависит от платформы;
для финальной публикации на iOS стоит добавить PNG apple-touch-icon.

Это подготовка PWA, не интеграция Telegram Mini Apps. Для Telegram отдельно нужны
бот, публичный HTTPS URL и проверка initData на сервере.

API и оригинальные изображения не кэшируются service worker: офлайн доступна только оболочка.
Выбранные теги, супер-теги и настройки хранятся в localStorage для текущего origin.
Другой порт или домен имеет отдельное хранилище. Очистка данных браузера удалит настройки.

Оригинал: `/#post=ID`, inline-поток `/api/original?id=ID&inline=1`.
Загрузка файла: `/api/original?id=ID`. Кнопка возврата и история браузера закрывают просмотр.
